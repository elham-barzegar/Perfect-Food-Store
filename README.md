# 🍔 Perfect Food Store

A modern and responsive food store web application built with Next.js, React, TypeScript and Tailwind CSS.

🌐 Live Demo:

https://food-store-sooty.vercel.app/


## 📌 Overview

Perfect Food Store is a modern frontend e-commerce project designed to provide a smooth and engaging shopping experience.

The project focuses on:

- Modern UI design
- Responsive layouts
- Reusable React components
- Clean code structure
- Performance optimization


## 🚀 Features

✅ Responsive design

✅ Modern food store interface

✅ Product showcase

✅ Reusable components

✅ Smooth animations

✅ Mobile-friendly experience


## 🛠 Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- JavaScript
- HTML5
- CSS3


## 📂 Getting Started

Clone the project:

```bash
git clone https://github.com/elham-barzegar/Perfect-Food-Store.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```


Open:

```
http://localhost:3000
```
